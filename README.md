Calculadora em Python

Calculadora simples feita em Python, que roda no terminal. Ela faz uma operação entre dois números e pergunta se você quer calcular de novo.
O que ela faz
Soma, subtração, multiplicação e divisão
Aceita números decimais (use ponto, por exemplo 2.5)
Avisa quando há divisão por zero
Avisa quando a operação digitada não existe
Pergunta se você quer calcular de novo e só aceita s ou n
